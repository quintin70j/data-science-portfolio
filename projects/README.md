# Public Projects

[Back to portfolio](../README.md)

This directory is the home for future public analytics and machine learning projects. **No completed public case studies are included yet.** The ideas below are planned directions, not completed work or verified model results.

| Planned direction | Question | Potential methods |
| --- | --- | --- |
| Operational performance analysis | Which patterns help explain variation in productivity? | Python, pandas, SQL, exploratory analysis, data visualization |
| Regression study | How accurately can an operational quantity be estimated? | scikit-learn, regression, pipelines, cross-validation, GridSearchCV |
| Classification study | How well can a clearly defined outcome be classified? | Classification, baseline comparison, precision/recall, cross-validation |
| Decision-support dashboard | Which measures best communicate performance and improvement opportunities? | Power BI or Excel, documented metrics, visual storytelling |

## Structure for each future project

```text
project-name/
├── README.md          # Question, data source, findings, and limitations
├── notebooks/         # Documented exploration and analysis
├── src/               # Reusable analysis code, when appropriate
├── reports/           # Shareable figures and summaries
└── requirements.txt   # Dependencies needed to reproduce the work
```

Each project should include:

- A clear business question and project status.
- A public data source with usage terms, or an explicitly labeled synthetic dataset.
- Reproduction instructions and documented dependencies.
- Data-quality checks, assumptions, and appropriate evaluation methods.
- Results that distinguish measured findings from estimates and hypotheses.
- Limitations and practical implications.

Only public or synthetic data and independently shareable code belong here. QUINTONE and FabricationAI remain private/proprietary projects; their code, algorithms, internal architecture, customer data, and implementation details are excluded.
